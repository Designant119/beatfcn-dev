03

打开 Linux

只做一次

这里不装任何程序。Python、torch、代码、数据全在打包好的系统里，导入一次就全有。要做的只有两下：把 Windows 自带的 Linux 开关打开（会要求重启一次），然后把那个包导进去。以后每天只用双击 run_server.bat。

已经导完了？以后每天只要这一步 双击仓库里的 run_server.bat → 弹一个黑窗口，服务在里面跑着，浏览器自动打开这个页面、顶部亮 LIVE。
这个窗口别关；关掉页面就退回手动模式（已经在跑的训练不受影响）。

为什么要重启：Windows 默认没开 Linux 这个功能，开它属于改动系统组件。这一步绕不过去，但一辈子只做一次。除了点“是”和重启，剩下的都是复制粘贴。

双击 run_server.bat 后，这页顶部亮了 LIVE亮了就说明环境齐了，下面的导入步骤不用碰。
第一次装：三条命令导入镜像，再一条起服务
管理员 PowerShell 打开 WSL 平台已经开着就跳过。装完要重启一次，重启完再回来。
ADMIN / POWERSHELL
wsl --install --no-distribution

这条报“不认识这个参数”，说明 Windows 太老或 WSL 是旧版：去掉 --no-distribution 直接跑 wsl --install，它会顺带装一个 Ubuntu，多一个不影响，后面导入的还是你自己的那个。

把打包好的系统导进来三个路径按实际位置改：起个名 / 装到哪 / 镜像包在哪。装到哪这格要落在他的 SSD 上，别落在硬盘上，否则训练读数据会慢。包要 NTFS 盘。
ADMIN / POWERSHELL
wsl --import beatfcn D:\wsl\beatfcn E:\beatfcn-train.tar --version 2

最后的 --version 2 别删，不加可能按 WSL 1 导进来，torch 会直接跑不了。D:\wsl\beatfcn 那格是这块 Linux 盘的落点，训练会把它撑大，别指到快满的分区。

这里起的名字 beatfcn 要跟 run_server.bat 里第二行的 set DISTRO=beatfcn 一致，不一致就双击不进去。

导入完默认是 root 用户不用也行，能跑。想换普通用户：微软文档写明 config --default-user 对导入的发行版无效，要写 /etc/wsl.conf 里的 [user] default=用户名。
镜像里没带代码时才需要：拉代码、装依赖、装 ffmpeg镜像是整套导出的就跳过这步。torch 那个轮子很大，慢是正常的，别中途 Ctrl+C。

        300
      


      

        数据加载进程是 CPU 的，不是显卡的，只吃内存、不吃显存。每个进程会把整份数据清单复制一份到内存里，满数据时约 3GB：16G 内存用 4，32G 最多到 8。这根只能往下调，往上拖超不过方案里写的数，超出那部分不生效
        
        4 个 · ≈12GB
